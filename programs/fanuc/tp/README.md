# Promoted Teach Pendant programs

This folder is **empty on purpose** until you promote a program from a **real cell**.

Do **not** copy `practice/fanuc/*/code/solution.ls` here. Drills stay under [`../../../practice/fanuc/`](../../../practice/fanuc/).

When you do promote:

```text
programs/fanuc/tp/<name>/
  code/     # controller listing (.ls)
  doc/      # guide.md — flowchart, diamonds, block-by-block
            # template: docs/_templates/program-guide.md
```

ATTR size fields on a real backup may be non-zero; study drills often show zeros.
